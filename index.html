Split a Word file into one document per page

Each page is saved as its own Word file, with a PDF copy if you want one. After you add a file, choose which details on the page, such as the student’s name or ID, go into the file names. The work happens in this browser, so the file is never uploaded anywhere.

Drop a Word file here

Word documents (.docx) only. You can add more than one.

A new document starts wherever the Word file has a page break. A page that only runs over because its text is long stays with the page before it.

The Word files keep the layout, logo, tables, stamp, header and footer of each page exactly. The PDFs are pictures of the page with searchable text, drawn by this browser.
